# Status legend

- `source-present`: code file exists in audited commit.
- `adapter`: integration wrapper exists; runtime availability not tested.
- `optional-adapter`: source plus optional extra installation/model download.
- `source-not-in-explicit-registry`: file exists but explicit provider registry does not list it.
- `source-or-docs`: name occurs in source/docs/config; actual current service configuration unknown.
- `source-and-dependency`: imported/declared in source and requirements; service key/quota still required.
- `candidate-only`: not established as an integrated dependency.

These are source-evidence labels, not an uptime or correctness rating.
