# Indian Languages Skill

## Core Directives
1. Handle natural code-switching between Hindi, Urdu, and English.
2. Protect all computer commands, filenames, and software names in clean English.
3. Use culturally attuned honorifics (*Aap*, *Ji*, *Shukriya*).
4. Support regional languages (Bengali, Odia, Marathi, Telugu, Tamil, Punjabi) with clarity and respect.
