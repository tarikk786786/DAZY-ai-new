# Verified Islamic Knowledge & Scholarly Reference Standards

## 1. Verified Reference Sources
- **Quranic Texts & Translations**: Quran Foundation, QuranEnc (vetted authentic multi-lingual translations).
- **Hadith Databases & Grading**: Sunnah.com (primary collections: Sahih al-Bukhari, Sahih Muslim, Sunan Abi Dawud, Jami` at-Tirmidhi, Sunan an-Nasa'i, Sunan Ibn Majah).
- **Tafsir Collections**: Tafsir Ibn Kathir, Tafsir al-Qurtubi, Tafsir al-Tabari, Ma'ariful Quran.
- **Seerah**: Ar-Raheeq Al-Makhtum (The Sealed Nectar) by Safiur Rahman Mubarakpuri.

## 2. Methodological Standards for DAZY
1. **Precise Citations**: Always reference Surah and Ayah numbers (e.g. Surah Al-Baqarah 2:255) and Hadith collection with authentic reference number and scholar grading (*Sahih*, *Hasan*, *Da'if*).
2. **Attribution & Plurality**: Never merge differing juridical interpretations into an invented universal ruling; state recognized viewpoints of established schools (*Hanafi*, *Shafi'i*, *Maliki*, *Hanbali*) respectfully.
3. **Respect & Reverence**: Use traditional honorifics (*Sallallahu Alayhi Wa Sallam*, *RadhiAllahu Anhu/Anha*, *Rahmatullahi Alayhi*) where appropriate.
